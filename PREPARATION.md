# Spot by NetApp Connector — Preparation

**Category:** C41. Cloud Cost Management (FinOps)  
**Status:** App Preparation Complete (Genuinely Vendor-Specific)  
**Standard:** APP_PREPARATION_STANDARD.md

## 1. Паспорт коннектора
- **Название:** Spot by NetApp Connector (`spot-netapp-connector`)
- **Официальный портал вендора:** https://spot.io
- **Базовый API:** `https://api.spotinst.io`
- **Модель аутентификации:** Personal Access Token (Authorization: Bearer <token>)
- **Назначение:** Интеграция платформы Imperal Cloud с Spot by NetApp для автоматизации предметной области: автоматизация использования спотовых инстансов AWS/GCP/Azure без риска падения продакшн-нагрузок.

## 2. Решаемая проблема
Когда **DevOps/SRE-инженер** сталкивается с задачей **автоматизация использования спотовых инстансов AWS/GCP/Azure без риска падения продакшн-нагрузок**, возникает необходимость ручного мониторинга, дублирования статусов и переключения между окнами. Это приводит к потере времени, замедлению реакции на инциденты и ошибкам ручного ввода.

## 3. Роли и права доступа
- **DevOps/SRE-инженер, технический директор**
- Принцип наименьших привилегий (Least Privilege): токен запрашивает доступ только к разрешенным операциям чтения и подтвержденным действиям.

## 4. Ключевые сущности
эласигруппы (/aws/ec2/elastigroup), кластеры Ocean (/ocean/aws/k8s/cluster), расчет экономии (/cost/analysis)

## 5. Первичный рабочий сценарий
`мониторинг пула спотовых инстансов -> прогноз вытеснения -> бесшовный перенос контейнеров`.

## 6. Границы коннектора
- Изолированное хранение секретов (BYOC).
- Никаких фиктивных методов сторонних предметных областей.
- Деструктивные операции требуют явного подтверждения пользователя.
